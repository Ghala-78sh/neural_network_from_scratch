# neural_network_from_scratch
A learning project that builds a neural network built from scratch using with Python and NumPy to classify handwritten digits from the MNIST dataset.

## Project Goal
Understand how neural networks work by implementing their mathematical operations directly, without using TensorFlow or PyTorch.

## Model Architecture
Input: 784 pixel values from a 28 × 28 grayscale image.
Hidden layer: ReLU activation.
Output layer: 10 classes representing digits from 0 to 9, with Softmax activation.

## Main Steps
Load and preprocess the dataset.
Initialize weights and biases.
Implement forward propagation.
Implement backpropagation.
Update weights and biases using gradient descent.
Evaluate predictions on held-out data.

## Tools
Python
NumPy
Google Colab

## How to Run
Open the notebook in Google Colab.
Provide the dataset required by the notebook.
Run the cells in order, from top to bottom.
